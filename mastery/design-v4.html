The standard way to show something can't exist. Next, it proves there are infinitely many primes.

Is √2 a fraction?

Here's a strange kind of claim: √2 is not a fraction. It doesn't tell you what √2 is; it tells you what it can never be. You can't check every fraction one by one. So how could you ever prove it? First, let's pin down exactly what we mean.

Definition 2.1 (Rational number). A real number x is rational if x = a/b for some a, b ∈ ℤ with b ≠ 0. Otherwise x is irrational.
In plain words: one whole number divided by another, like 7/5.
Definition 2.2 (Even, odd). An integer n is even if n = 2k for some k ∈ ℤ, and odd if n = 2k + 1 for some k ∈ ℤ.
10 = 2 · 5 is even; 7 = 2 · 3 + 1 is odd.

Now the idea. Suppose, just for a moment, that √2 is a fraction. We aren't claiming it; we're taking it for a walk to see where it goes.

Theorem 2.3. √2 is irrational.
Proof.

The idea

A tool built by the Cambridge maths and computing community: typeset like a Tripos paper, operated like a good piece of software. Quiet surfaces, precise type, numbers in monospace, every action reachable by keyboard.

Rules

One primary action per screen, in ink. Cambridge green only for "now" and progress; scarlet only for things that need you. Hairlines, no shadows inside the app. Labels in mono capitals; content in serif. Desktop gets a left rail, number keys for tabs, and ⌘K to jump anywhere.
